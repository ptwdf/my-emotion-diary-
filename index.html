常见问题

🔒 我的数据存在哪里？会被上传吗？
所有记录只保存在你当前浏览器本地的 LocalStorage 里，不会上传到任何服务器，也不需要注册登录。因此换设备、换浏览器或清除浏览器数据后，记录不会自动同步过来。
🧹 清除浏览器缓存会怎样？
在浏览器设置里执行「清除网站数据 / 清除缓存」会连同记录一起删掉，且无法找回。建议定期点击右上角 ☁️ 图标，用「导出文件」或「复制」保存一份备份。
📱 无法添加到主屏幕怎么办？
iPhone必须用 Safari 浏览器打开本页面：点击底部中间的「分享」按钮 ⬆️ → 向下滑动找到「添加到主屏幕」→ 点右上角「添加」。如果找不到这个选项，通常是因为正在微信 / QQ 等内置浏览器里打开，请先点「···」选择「在 Safari 中打开」。
安卓请用 Chrome 浏览器或系统自带浏览器打开：点击右上角「⋮」菜单 → 选择「添加到主屏幕」或「安装应用」→ 确认即可。部分国产浏览器不提供该选项，建议复制链接到 Chrome 中打开。
💾 怎么备份和恢复？
  • 备份：点右上角 ☁️ → 点「生成备份」→ 再点「导出文件」，会下载一个 JSON 文件；也可以点「复制」，把内容粘贴到备忘录里保存。
  • 恢复：在同一个弹窗下方点「选择备份文件」选中 JSON 文件，或把内容粘贴进输入框，再点「导入恢复」。
  • 注意：导入是「全量覆盖」，会替换当前所有记录，导入前会有确认提示。备份文件中已包含你自定义的情绪设置。
⬇️ 点了「导出文件」没反应？
微信、QQ 等内置浏览器可能拦截文件下载。请点右上角「···」选择「在浏览器中打开」后重试；或者直接使用「复制」按钮，把备份内容粘贴保存到备忘录 / 聊天框里，恢复时再粘贴回来即可。
📲 添加到主屏幕后，点下载备份没反应？
iPhone在「添加到主屏幕」的独立窗口里，部分 iOS 版本会静默拦截文件下载。请改用 Safari 标签页打开本页面，再点右上角 ☁️ →「导出文件」；下载好的文件在「文件」App →「下载」里。
安卓在 PWA 独立窗口里下载偶尔也会被拦截。请改用 Chrome 浏览器标签页打开本页重试，文件会保存到「下载」目录。如果仍然不行，用「复制」按钮把备份内容粘贴到备忘录保存，恢复时再粘贴回来即可。
⚙️ 如何自定义情绪？
点击右上角的 ⚙️ 打开情绪设置。默认情绪仅可修改图标；可新增、编辑、删除自定义情绪。主页面记录时，若情绪太多，点击「展开更多」即可看到全部。设置修改后会自动同步到主页面。
